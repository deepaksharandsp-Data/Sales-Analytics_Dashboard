# Sales Analytics Dashboard

## Project Overview
This project demonstrates end-to-end sales data analysis using Microsoft Excel and MySQL. It includes an interactive Excel dashboard and SQL queries that generate business insights from sales data.

## Tools Used
- Microsoft Excel
- MySQL
- SQL

## Project Files
- Global_Superstore.csv
- Sales_Analytics_Dashboard.xlsx
- Sales_Analytics_SQL_Queries.sql

## SQL Analysis
The project contains 30 SQL queries covering:
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- HAVING
- CASE
- SUM
- AVG
- COUNT
- LIMIT

## Business Insights
- Sales by Category
- Profit by Region
- Top Customers
- Top Products
- Sales by Segment
- Customer Analysis
- Product Performance

## Skills Demonstrated
- Data Cleaning
- Data Analysis
- SQL Query Writing
- Dashboard Creation
- Business Reporting
